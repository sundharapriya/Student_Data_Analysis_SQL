# Student Career Analysis – SQL Project

##  Project Overview

**Student Career Analysis** is a SQL-based data analytics project that analyzes students' academic performance, skills, career interests, internships, certifications, job goals, and placement status.

The project uses SQL queries to extract meaningful insights from student career data and understand the factors that may influence career outcomes.

##  Objectives

* Analyze students' academic and career information.
* Identify popular career interests and job goals.
* Analyze placement status.
* Compare skills, certifications, internships, and experience.
* Study preferred locations and work modes.
* Analyze expected salary based on different factors.
* Practice SQL queries for real-world data analysis.

##  Dataset

* The dataset contains student career-related information, including academic performance, skills, internships, career interests, job preferences, salary expectations, certifications, and placement status. It can be used to analyze career preferences, skill development, placement trends, and factors influencing students' career outcomes.

##  Technologies Used

* **MySQL**
* **SQL**

##  Key Analysis Areas

* **Academic Performance** – CGPA & backlogs
* **Career Preferences** – Interests & job goals
* **Skills** – Programming & communication
* **Placement** – Placement status & internships
* **Salary** – Expected salary & experience

### Salary Analysis

* Average expected salary
* Salary based on experience
* Salary based on internships
* Salary based on job goals
* Salary comparison across departments

## Key Insights

This project helps understand how different factors such as **CGPA, internships, certifications, technical skills, communication skills, and career interests** can be analyzed to identify student career trends.

The analysis can be useful for:

* Career guidance
* Placement analysis
* Student performance tracking
* Skill-gap identification
* Career planning

###  Conclusion

This project provides insights into student career trends by analyzing academic performance, skills, internships, career preferences, and placement status. It helps identify patterns that can support career planning, placement analysis, and skill development.
